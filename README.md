# AI Coding Template instructions
1. branch off the commit "New Template" (not the initial commit)
2. check the metadata files: remove examples, specify ROE for the AI, setup limitations & expectations, define allowed-to-use programming languages & the level of complexity of the written code etc.
3. adapt spec and progress for every feature/commit in order to specify the instructions for the AI
4. use the prompt template in PROMPTS.md - new chat for every feature
5. for learning: focus on 2-3 concepts, read the comments the AI generates

# Example step sequence for the whole project
0. Sketch the feature w/ pen & paper (UIXD) or a dedicated tool - internal logic, visuals etc.
# steps by the example MTPR flashcards
1. HTML skeleton: form and empty list, no JS
2. Basic CSS layout: one column, readable font
3. Clicking "Add" shows the pair in the list (in memory only)
4. Empty fields can't be submitted; form clears after adding
5. Save and load with localStorage
6. Delete button per pair
7. "Start practice" button shows one card (English side)
8. Click card to reveal German
9. "Next" shows a random different card
10. "I knew it" counter
